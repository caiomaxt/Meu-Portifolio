# 🚀 Meu Portfólio & Exercícios Práticos

Repositório criado para reunir meus projetos e exercícios de fixação desenvolvidos em HTML puro.

## 📁 Estrutura do Projeto

- **`portifolio.html`**: Página principal do portfólio, contendo minha apresentação, informações estruturadas e links de contato.
- **`pratica.html`**: Página dedicada a testes, treinos e exercícios de marcação de texto e elementos HTML.
- **`Biografia.html`**: Página com minha biografia, foto, time do coração, hobby e um vídeo do YouTube que mais curto.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica e marcação de conteúdo (sem estilização CSS).
